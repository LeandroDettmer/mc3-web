    Midnight Club 3: DUB Edition Remix in the browser: the Xbox game's own code, statically recompiled to C with xboxrecomp and built for WebAssembly, drawn with WebGPU (WebGL 2 as a fallback). Plays on PC, phones (touch controls) and TVs, with keyboard or controller.

    Online: free roam with other players in the same city, and the garage with every car and part unlocked. Your online profile is kept in this browser.

    You need your own copy of the game: extract your disc and serve it from your own machine with tools/web_serve.py or web/server. Nothing of the game ships with this page; saves stay in this browser.

    Source: github.com/LeandroDettmer/mc3-web. Bugs and ideas: open an issue there; contributions by fork and pull request.

    mcdub3 web by Leandro Dettmer, a browser port of mcdub3-nx by Laure Ladastra (MIT).

    Built on xboxrecomp, the Xbox static recompilation toolkit by Ned Heller (sp00nznet) and its contributors (xboxrecomp/CONTRIBUTORS.md; MIT).

    Modelled on antoxa2584x's nfsu2-sw.

    This start page follows th0mk's nfsu2-web (MIT), whose free-roam networking the online mode is ported from; itself based on Talha Müderrisoğlu's NFSU2Recomp.

    Passed to the game:

    The keyboard is pad 1 (Settings, Keyboard to turn it off). Click the game first so it gets the keys.

      Xbox, PlayStation and other controllers work through the browser's Gamepad API, as pads 1 to 4 in the order they are connected; one plugged in later is picked up within a second. Press a button on it once the game is running so the browser shows it to the page.

      Only this controller drives pad 1 here, so two tabs can each use their own. Remembered for this tab only. The keyboard acts on the focused tab.

      The keyboard stays on top of pad 1. Buttons sit where the Xbox pad has them: A, B, X, Y, Start, Back, the triggers, White and Black on the shoulders, both sticks and their clicks.

      Profiles in this browser

        Saved in this browser's private storage (OPFS), under UDATA/54540079/. Import takes a profile's .mc3 from an Xbox and signs it for the port; memory-unit images (.gsx) come later, until then make import-save FILE=…. PS2 profiles can't be used.

        System Link

        The game's own System Link, carried by the server: everyone who plays on the same server meets as if on one LAN, and finds the others' games in the System Link menu.

        With System Link on, this page joins the server's virtual LAN (web/server, its /lan switch) and the game plays on it (the Remix; native builds use the local network, RECOMP_NET_* switches).

        The Remix's System Link menu. MC3_NETPLAY

        What other players will see. Shown in the game's sign-in texts and on the server link.

        Online profile

        Free Roam's money and garage, apart from your career, in this browser's private storage (online/profile.bin). Saved when you leave the garage and when you go back to Career, Tokyo or Arcade. An import counts from the next Free Roam.

        Races

        Make a race or join one here, before or while the game runs. Then in the game: Online, Online Races, and Host or Join Game: only the players of your race show there. Not in a race: you meet everyone else not in one, as before.

        Turn System Link on to see the races on this server.
